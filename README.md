# 📊 Telco Customer Churn Prediction

A Machine Learning project focused on predicting customer churn using statistical analysis and ensemble learning.

## 📌 Features
- **Statistical Analysis:** Non-parametric hypothesis testing (Mann-Whitney U, Chi-Square, Cramér’s V, Spearman Correlation).
- **Advanced Modeling:** Triple Gradient Boosting (CatBoost, XGBoost, LightGBM) optimized with **Optuna**.
- **Ensemble Learning:** Combined models using a **Stacking Classifier** for maximum accuracy.

## 🛠️ Tech Stack
- **Python** (Pandas, NumPy, SciPy)
- **Machine Learning:** Scikit-Learn, XGBoost, LightGBM, CatBoost
- **Optimization:** Optuna
